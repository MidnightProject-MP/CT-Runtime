# vNext acceptance

The first vNext milestone is an autonomous outer-loop proof, not a migration.

A Feedback wake reconstructs one Work Unit; justified work gets one disposable
Execution; cognition returns the #22 turn; evidence and continuation are
persisted; the execution ends. A later wake may create a new execution. No
handoff or pre-created successor is required.

A `done` claim is independently verified and remains non-authoritative unless
an independent terminal authority authorizes completion. Otherwise the Work
Unit is quiescent or awaiting review.

Only Work Unit, Execution, claim/fence, Continuation, wake/event, evidence
reference, and transition integrity are in the vNext kernel. Old Runtime,
Federation handoffs, schedules, Observer, Convergence, and provider-specific
execution remain outside the path.
